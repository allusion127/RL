# T6_T4 최적화 과정 시각화 (2026-08-15)

RL 캠페인이 `T6_T4` 셀에서 최소 `F_r` 노심을 찾아가는 **과정 자체**를 그린 그림 묶음이다.
소스는 모두 읽기 전용으로만 접근했다 — `data/store/records.parquet`, `data/store/maps.npz`,
그리고 라운드별 웨이브 번호를 담은 `*_labels.jsonl` (스크래치패드).

## 공통 데이터 정의 (모든 그림에 동일 적용)

* **대상 행** — `campaign`이 `fpcamp_minfr_T6T4*`인 930행. 이 중 `converged == True`이고
  `f_r`/`cyclen`이 있는 **790행**이 그림에 들어간다 (수렴률 84.9%).
* **라운드** — 저장소의 append 순서가 그대로 시간순이고, 라운드 블록이 정확히 끊긴다.
  `r3`~`r7`은 각 100콜. **`r2`는 사전 캠페인 블록 430콜 전체**를 하나로 묶은 것이다
  (로컬 부트스트랩 웨이브 148행 + 199 원격 풀 100행 + 나머지 182행이 같은 캠페인 이름
  `fpcamp_minfr_T6T4`으로 한 덩어리로 쌓여 있어 더 잘게 쪼갤 근거가 없다).
* **밴드내 실현가능(in-band feasible)** — `620 ≤ cyclen ≤ 645 EFPD` **그리고** `F_r ≤ 1.55`.
* **maps 커버리지** — `maps.npz`는 `record_id`를 키로 쓴다. 대상 930행 중 790행에 맵이 있고,
  이는 **수렴행의 100.0%** (전체 시도행 기준 84.9%)다. 미수렴행에는 맵이 없다.
  즉 출력분포 그림에는 커버리지 구멍이 없다.
* **출력맵 채널** — `(4, 9, 9)` EDIT5 스택의 채널 0 = **BOC 집합체 출력**만 썼다
  (EOC 출력/연소도/kinf는 쓰지 않았다). 맵은 이미 다중도 가중 노심평균 1.0000으로
  규격화되어 있어 셀 값이 곧 상대출력이고 최대값이 곧 F_xy다.
* **전노심 전개** — `lpopt/data/flatness.py`의 기존 헬퍼(`_core_geometry`, `_CORE_MASK`,
  `_SLOT_OF`, `SLOT_WEIGHTS`, `SLOT_RADIUS`)를 그대로 재사용해 69슬롯 → 17×17로 미러 전개했다.
* **연료 분류** — 이 설계는 `n_batches = 2`, `feed = 121`인 **2배치 평형노심**이라 *2주기 연소재*가
  존재하지 않는다. 전 패턴의 셔플 카드가 `restart = 1` 하나뿐임을 확인했다. 그래서 3색 범주는
  "신연료 / 1주기 연소재 / 2주기 연소재"가 아니라 **신연료 T6(5.04 w/o, Gd 16본) /
  신연료 T4(4.74 w/o, Gd 24본) / 1주기 연소 재장전**이다 (전노심 56 + 65 + 120 = 241기).

## `opt_radial_evolution.gif` — 헤드라인

밴드내 실현가능 `F_r`이 **엄격히 개선된 순간만** 프레임으로 잡은 13프레임 애니메이션이다
(1060×560, 0.55 MB, 첫/마지막 2초 · 나머지 0.9초, 무한 반복). 프레임 순서는 저장소 append
순서 = 실제 계산 순서다. 왼쪽은 전노심 장전 모형(3색 범주), 오른쪽은 같은 노심의 BOC 상대출력을
**1.0을 중심으로 한 발산형 컬러맵**(파랑 <1.0, 회색 ≈1.0, 빨강 >1.0)으로 그린 것이며, 첨두 집합체는
검은 테두리 + 값 라벨로 표시했다. 컬러 스케일은 13프레임 전체에 걸쳐 **고정**(0.28–1.36,
중심 1.0)이라 프레임 간 색이 직접 비교된다.

궤적: `1.5231 → 1.5209 → 1.5131 → 1.5082` (r2) `→ 1.5018` (r3)
`→ 1.4982 → 1.4978 → 1.4962 → 1.4929 → 1.4866` (r4) `→ 1.4859 → 1.4845 → 1.4797` (r6).

**정직한 단서:** (1) 프레임은 *개선 순간만*이라 r5·r7은 아예 등장하지 않는다 — 그 두 라운드는
누적 최우수를 갱신하지 못했다. (2) 시작 프레임은 "r2 라운드의 첫 실현가능 노심"이 아니라
"밴드내 실현가능 조건을 만족한 최초의 갱신"이다. r2 원격 풀 100행의 최우수 실현가능 노심은
`F_r = 1.5444 @ 619.93 EFPD`로, 밴드 하한을 **0.07 EFPD 차이로** 벗어나 이 사슬에는 못 들어온다.
(3) 프레임 수 13은 요구 하한 6을 넘으므로 규칙 완화는 하지 않았다.

`opt_start.png` / `opt_best.png`는 첫·마지막 프레임을 고해상도로 저장한 것이고,
`opt_before_after.png`는 둘을 2×2로 나란히 놓은 것이다 (`F_r` 1.5231 → 1.4797, −0.0434 /
`F_xy` 1.345 → 1.304).

## `budget_curve.png`

x축은 **누적 MASTER 호출 수**(총 930), y축은 그 시점까지의 **밴드내 실현가능 최우수 `F_r`**을
계단으로 그린 것이다. 라운드 경계는 세로 헤어라인, 각 라운드 위에는 그 라운드 자체의 최우수값과
모델 세대 · λ 태그를 직접 라벨로 붙였다. `ga80` 기준 노심 `1.4636`은 점선 기준선이다.

라운드별 최우수(재계산값): r2 `1.5082` · r3 `1.5018` · r4 `1.4866` · r5 `1.4972` · r6 `1.4797` ·
r7 `1.4850`.

**정직한 단서:** (1) 과제에서 받은 r2 = 1.544는 **r2 원격 풀 100행만**의 실현가능 최우수이고,
그 노심은 619.93 EFPD로 밴드 밖이다. 저장소 기준으로 r2 블록 430콜 전체의 밴드내 실현가능
최우수는 `1.5082`이며 그림은 이쪽을 쓴다. r3~r7은 과제 제시값과 소수 4자리까지 일치한다.
(2) 100콜/라운드는 r3 이후에만 맞다 — r2 블록은 430콜이라 x축의 앞 46%를 차지한다.
(3) 점선 기준 `ga80 1.4636`은 **다른 셀(E1_E2) · 다른 핵종라이브러리(ga80)** 레코드다.
같은 조건에서의 목표선이 아니라 "이 프로그램이 지금까지 본 최저 F_r"이라는 참고선일 뿐이다.
(4) 라운드 ↔ 모델 세대(split_S1b → s1c → s1d → s1e) 대응은 `data/models/*` 디렉터리
타임스탬프와 라운드 풀 시각을 맞춘 **추정**이다. λ 200 → 400 전환만은
`fpcamp_minfr_T6T4_199.inp`의 `minfr_lambda = 400.0  # raised from 200 (2026-08-14): r4/r5
measured the search sliding…` 주석으로 확정된 사실이다.

## `band_scatter.png`

수렴 790기 전부를 `cyclen`(x) vs `F_r`(y)로 뿌리고 라운드를 **단일 색상(파랑) 순차 램프**로
칠했다(밝음 = 이른 라운드). 620–645 EFPD 밴드는 회색 음영, `F_r = 1.55` 제한은 점선이다.

이 그림이 말하는 것은 λ 이야기다. 라운드별 밴드내 비율이
r2 27% → r3 26% → r4 71% → **r5 33%** → r6 97% → r7 99%로 움직인다. r5에서 λ=200이 허용한
"F_r 0.025당 5 EFPD" 교환 때문에 탐색이 밴드 왼쪽(615–619 EFPD)으로 미끄러졌고 — 그 라운드의
`F_r` 최저값 `1.4812`는 618.6 EFPD로 밴드 밖이다 — λ=400으로 올린 r6에서 곧바로 밴드 안으로
다시 모인다.

**정직한 단서:** 점이 790개라 밴드 안쪽 저-`F_r` 구역은 상당히 겹친다(과밀). 개별 점을 읽는
그림이 아니라 무리의 이동을 읽는 그림이다. 미수렴 140행은 빠져 있다.

## `ring_strategy.png`

왼쪽: 슬롯 반경의 **다중도 가중 3분위**(내측 79기 / 중간 78기 / 외곽 84기)별 신연료 비율을
세 그룹(전체 수렴 평균 / `F_r` 최상위 20기 / `node_peak` 최상위 20기)으로 묶은 막대.
오른쪽: 같은 링 구분으로 본 **시작 노심 vs 최종 최우수 노심의 링 평균 상대출력**.

읽히는 것: 이 셀의 반경방향 서명은 뚜렷한 **out-in(저누설 반대)** 이다 — 신연료가 외곽 링에
65%, 내측 45%, 중간 39%로 들어간다. 그런데 **세 그룹이 거의 구별되지 않는다**
(내측 45/44/44, 중간 39/38/38, 외곽 65/67/67 %). 최상위 노심이 평균 노심과 다른 점은
"신연료를 어느 링에 넣느냐"가 아니라 **링 안에서 어떻게 배열하느냐**라는 뜻이다.

**정직한 단서:** 링 경계는 반경 3분위라는 임의 선택이고(가중 기준이라 각 링이 약 80기),
상위 20기는 밴드내 실현가능 행에서만 뽑았다. 오른쪽 패널은 두 노심의 단일 비교라
분포가 아니라 예시다.
