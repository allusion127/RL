# 메쉬 그림 표준 양식 (style2) — 2026-08-17

사용자가 `feasible_database.xlsx` 로부터 그린 참조 그림을 업로드하고 **이후 모든
메쉬(격자) 그림은 이 양식을 따르라**고 지시했다. 이 문서가 그 사양이다 — 앞으로
메쉬 그림을 그리는 모든 스크립트는 이 파일을 인용해야 한다.

적용 대상: `(e_core × feed)` 재장전 설계지도류 그림 전부. 첫 적용:
`mesh_v3_fig.py`(v3, 90셀) / `scoping_mesh_fig.py`(v2, 55셀)의 style2 렌더러
(`mesh_style2_fig.py`).

## 1. 축

| 축 | 의미 | 단위 |
|---|---|---|
| x | 주기길이 | EFPD |
| y | 방출연소도 (평형 질량수지, `B_d = cyclen·P_th/M_HM/1000·N_FA/feed`) | GWd/tU |

## 2. Iso-feed 선 (같은 feed, 여러 농축도를 잇는 선)

feed 마다 고유 색, 실선, 두께 ~2pt. 라벨(`"feed 109"`)은 선 자기 색으로, 선의
**시작(왼쪽 끝, 그 feed 선 위 최소 x 노드)** 근처에 붙인다.

색은 ColorBrewer `Set1`(핑크·갈색·보라·초록·빨강·파랑, 사용자가 지목한 6색과
일치)에 `Dark2`의 청록 1색을 더해 8색으로 확장했다 — feed 101→129, 0.1 간격
농축도 라벨과 절대 혼동되지 않도록 이름이 있는 정성적(categorical) 팔레트에서만
고른다. `node`(node.js) 가 이 환경에 없어 `dataviz` 스킬의
`validate_palette.js` 를 직접 돌리지는 못했다 — 대신 전부 문헌상 검증된
정성 팔레트(Brewer Set1/Dark2)에서만 값을 가져와 임의 보간을 피했다.

## 3. Iso-enrichment 연결선 (같은 농축도, 여러 feed 를 잇는 선)

가늘게, 회색(`#A5ABB3`), zorder 를 iso-feed 선보다 아래로. 라벨(`"5.3 w/o"`)은
그 색(아래 §4)으로, 선의 **오른쪽 끝(그 농축도 선 위 최대 x 노드)** 근처에
붙인다. 오른쪽 끝이 몰리는 구간은 라벨을 수직으로 벌리고 원래 노드까지
가는 실선(hairline)을 그어 어느 노드의 라벨인지 항상 추적 가능하게 한다 —
겹침 금지.

## 4. 노드 FILL — 농축도

순차적(sequential-ish)이되 고농축 끝에서 진한색이 서로 구별되도록 이산적으로
고른 세트. 참조 그림의 `5.0 갈색 … 5.5 검정`을 앵커로 삼고, 확장 영역
5.6–6.5 는 저채도·저명도 색상을 색상환으로 돌려가며 이어간다(더 어둡게는
갈 수 없으므로 "sequential-ish" — 어둡기는 유지하고 색상만 돌린다).

## 5. 노드 RING — 봉최대(핀) 연소도 등급

테두리(edge) 두께 ~2.5pt. 예측 max pin BU 가 없는 노드는 반드시 **미산출
(회색)** 으로 두고 다른 등급으로 채우지 않는다 — 완전성보다 정직성.

| 등급 | 조건 (GWd/tU) | hex |
|---|---|---|
| green | < 62 | `#2E9E4F` |
| yellow | 62 ≤ · < 68 | `#E8B923` |
| orange | 68 ≤ · < 75 | `#E07B39` |
| red | ≥ 75 | `#C0392B` |
| 미산출 | 예측값 없음 | `#9AA5B5` |

**데이터 출처 우선순위**: (1) `mesh_nodes.csv` 의 `pred_max_pin_bu` (셀 대표 후보
자체 예측값) → (2) 그 셀을 겨냥한 전용 캠페인 보고서의 실측/예측 값(있는 경우,
주석으로 출처 명시) → (3) 없으면 미산출. 캠페인 값을 셀 대표 노드에 갖다 붙이는
것은 근사다고 명시한다 — 대표 후보와 캠페인 프런티어 후보가 동일 코어가
아닐 수 있다.

## 6. 배경 구름

수렴(`valid ∧ converged`) 저장소 전 행을 `(cyclen, B_d)` 로, 농축도별 §4
색으로, 아주 옅게(`alpha ≈ 0.10`), 작게(`ms ≈ 3–4`) 찍는다. 노드/선보다
zorder 가 낮아야 한다.

## 7. 범례

박스 없이(house style), 2단(two-column)으로: 왼쪽 열 = 농축도 채움색, 오른쪽
열 = 링 등급(미산출 포함). 제목·부제·각주는 이 저장소의 기존 하우스 스타일
(잉크 `#1A1A1A`, 뮤트 텍스트 `#8A8A8A`)을 따른다.

## 8. 검수

렌더 후 100%·50% 확대로 읽어 라벨 겹침·한글 폰트(`Malgun Gothic`) 정상 표시를
직접 확인한다. 자동 팔레트 검증기(`validate_palette.js`)가 있는 환경에서는
`--mode light`로 재검증을 권장한다(§2 참조 — 이번 렌더 환경에는 node.js 가
없어 생략했다).
