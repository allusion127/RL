# 고농축 확장 메쉬 v3 (e_core 5.0–6.5 × feed 109–129) — 사전등록 (PRE-REGISTRATION)

**작성 2026-08-17, MASTER 체인을 한 건도 던지기 전.** A/B 단계는 MASTER 소비가
없고(대리모델·해석모델 전용), C 단계만 실물 계산을 쓴다. 본 문서는 C의 **배분
규칙과 예산 상한을 결과를 보기 전에** 고정하기 위해 A/B 착수 시점에 함께 쓴다.

지시 원문 취지: *고농축 구간(6.0–6.5 wt%, 실제 DB에도 없음)은 표준 안전여유로는
가능해가 0이므로 안전계수를 유연하게 완화하라. 희소 구간은 실제 MASTER 계산으로
최소·표적 충전하라. 그리고 순수 선형반응도모형(LRM) 메쉬와 비교하라 — "아마 LRM이
꽤나 정확할거야".*

## 1. 사전등록 항목 A — LRM 백본 메쉬 (MASTER 0)

### 1a. 모형과 계수 (고정, 재적합 없음)

`data/reports/dbx_lrm_fit.csv` (6,113 노심 적합, `dbx/make_lrm.py`) 의
**모형 B(평균)** 와 **ceiling 백본**을 그대로 쓴다. 재적합하지 않는다.

```
EFPD_mean(e,F) = alpha_B(F)  * (a_B  + b_B  * e)   a_B  = -14.854288  b_B  = 126.132069
EFPD_ceil(e,F) = alpha_C(F)  * (a_C  + b_C  * e)   a_C  =  +3.369285  b_C  = 122.239281
```

적합된 alpha (feed 101–121):

| feed | 101 | 105 | 109 | 113 | 117 | 121 |
|---|---|---|---|---|---|---|
| `alpha_B` | 0.903213 | 0.931299 | 0.967220 | 0.987078 | 1.003856 | 1.019689 |
| `alpha_C` | 0.912776 | 0.941476 | 0.973457 | 0.994604 | 1.014169 | 1.027840 |

### 1b. f125 / f129 의 alpha 외삽 — 형식 선택을 **결과 전에** 고정

5개 후보 형식(feed 선형 / feed 2차 / `1/(n_b+1)` 선형 / `1/(n_b+1)` 2차 /
`log(feed)` 선형)을 (i) 6개 적합 feed 상의 leave-one-out RMS 와 (ii) **저장소
MASTER 실측 비율 검정**으로 심판한다.

**검정 (ii) 의 정의 — 이것이 채택 기준이다.** 동일 pair 를 여러 feed 에서
돌린 저장소 행만 쓰면 농축도·라이브러리 효과가 상쇄된다. pair 당 feed 별
`q95(cyclen)` 을 그 pair 의 f117 값으로 정규화한 비율을 feed 응답의 실측치로
보고, 각 외삽 형식이 f125/f129 에서 만드는 비율과 비교한다. 셀 조건
`n ≥ 25`, pair 당 `≥ 4` feed.

> **채택 규칙 (사전 고정):** f125·f129 에서 실측 비율과의 편차가 가장 작은
> 형식을 채택한다. LOO 는 참고치로만 보고한다 (LOO 는 외삽이 아니라 내삽을
> 재는 지표이므로 단독 근거로 쓰지 않는다).

f125·f129 열의 모든 셀은 `alpha_source = extrapolated_<form>` 로 **표시**하고,
그림에서 별도 해칭으로 구분한다.

### 1c. 질량수지 (v2 와 동일, 변경 없음)

```
B_cycle = EFPD * P_th / M_HM / 1000       P_th = 3983.0 MW
B_d     = B_cycle * 241 / feed            M_HM = 241 * u_mass_g * 8 * 381 / 1e6
```

`u_mass_g` 는 셀 pair 평균, ga80(전량 NaN)은 `FALLBACK_U_MASS_G = 138.9`.
paramA 실측 범위는 138.07–139.45 (±0.5%) 이므로 **라이브러리 간 M_HM 차이에
대한 EFPD 보정은 하지 않고**, ≤0.5% 잔차로 보고만 한다.

### 1d. LRM 검증 — 사용자 가설의 정량 심판 (MASTER 0)

DB 적합 범위는 **e 5.0–5.5, feed 101–121**. 메쉬는 **e 6.36, feed 129** 까지
간다 — 농축도축 0.86 wt% (적합폭의 172%), feed 축 2 스텝의 외삽이다.

저장소에는 **paramA 고농축(e 5.79–6.36) MASTER 행이 f109/117/121/125 에 이미
존재**한다. 따라서 LRM 을 실물 대비 **홀드아웃 검정**할 수 있다:

> **사전 고정 판정 기준.** LRM ceiling 백본이 저장소 고농축 셀(e > 5.55) 의
> `q95(cyclen)` 을 예측할 때
> **(a) 편향 |bias| < 2% 이고 (b) rms < 3%** 이면 사용자 가설
> *"LRM이 꽤나 정확할 것"* 을 **확증(confirmed)**,
> 편향 2–5% 또는 rms 3–6% 이면 **부분 확증(partially confirmed)**,
> 그 밖은 **기각(rejected)** 으로 보고한다.
> 부수적으로 feed 고정효과를 통제한 2원 회귀로 **농축도 기울기 오차**
> `b_ceil` 대비 %와 그 95% 부트스트랩 CI 를 보고한다.

## 2. 사전등록 항목 B — 대리모델 메쉬 v3 (MASTER 0)

### 2a. 격자

`E_TARGETS = 5.0 … 6.5` (0.1 간격, **16 준위**), `FEEDS = {109,113,117,121,125,129}`
→ **96 셀**. v2 대비 f105 를 빼고 f125·f129 를 넣었다 (지시 격자).

pair 선정 규칙은 **v2 규칙을 그대로 유지**한다 (`dbin` → `spread` → `sup_pair`).
v2 와의 중첩 구간(e5.0–6.0 × f109–121, 30 셀) 비교 가능성을 지키기 위해서다.
단, `pair_selection.csv` 에 **앵커용 대안 pair** 열을 추가로 기록한다:
목표 |Δe| ≤ 0.06 안에서 `(메쉬 feed 지지 개수 ↓, 총 저장소 행수 ↓, spread ↑)`
로 정렬한 1위. C 단계의 MASTER 앵커는 **이 대안 pair** 를 쓴다 (재시작 자산이
있는 pair 여야 실물이 돈다).

### 2b. 계층형 가능성 게이트 (TIERED) — 사전 고정

F_q ≤ 2.41, CBC_max ≤ 1600 ppm, |AO| ≤ 0.30 은 **모든 계층에서 불변**.
완화하는 것은 **F_r 하나뿐**이다.

| 계층 | F_r 상한 | 성격 |
|---|---|---|
| **Tier-1 표준** | ≤ 1.55 | 프로젝트 표준 제약집합 (v2 와 동일) |
| **Tier-2 완화** | ≤ 1.65 | 설계여유 완화 구간 |
| **Tier-3 관찰** | ≤ 1.80 | 관찰 전용 — 인허가 주장 근거 아님 |

**셀마다 `min_pred_f_r` (달성 가능 최소 F_r) 를 반드시 기록**한다. 지도는
이진 판정이 아니라 **등고선**으로 읽는다 (지시 명시).

> **착수 전 경고 (기록용).** 저장소의 실물 MASTER 진실은 e ≥ 5.8 paramA pair
> 10종·약 10,000 행에서 **셀별 최소 F_r 이 1.73–2.08**, 어떤 셀도 1.73 미만이
> 없다. 즉 Tier-1·Tier-2 는 고농축에서 **실물로도 0**일 가능성이 높고,
> Tier-3(1.80) 조차 경계선이다. 이 예상은 **결과를 보기 전에** 적어 둔다.
> 만약 대리모델이 고농축에서 Tier-1/2 가능해를 다수 보고하면 그것은 발견이
> 아니라 **외삽 낙관 편향의 증거**로 취급한다.

### 2c. 실행 계층 라벨 (그림·표 공통, 한국어)

- `실현 확인` — 해당 (pair, feed) 에 수렴된 저장소 행이 있음
- `미발견` — 자산은 있으나 가능해를 찾지 못함
- `격자-우회(fallback)` — 원 feed 재시작 자산이 없고 `pair_feed` 인접 feed
  fallback 으로만 실현 (f113/f129 고농축)
- `실현 불가(격자)` — 연료 격자 자체가 그 e_core 를 만들지 못함 (e6.5 행)

## 3. 사전등록 항목 C — 최소 MASTER 앵커링 (실물 소비)

### 3a. 예산 상한 (하드 캡)

**총 250 MASTER 체인.** 초과 시 즉시 중단하고 미집행분을 보고한다. 배분:

| 항목 | 체인 | 셀 수 | 근거 |
|---|---|---|---|
| 탐침 체인 (probe) | **≤ 160** | 10–16 | 셀당 8–16 체인 |
| 미니 개통 캠페인 | **≤ 80** | 1–2 | 캠페인당 30–50 호출 |
| 예비 (재시도·실패 흡수) | **≤ 10** | — | |
| **합계** | **≤ 250** | | |

### 3b. 앵커 셀 순위 규칙 (결과 보기 전 고정)

셀별 점수

```
score = w_gap * GAP + w_dis * DIS + w_reach * REACH
```

- `GAP` = 지지 희소도. `n_store_pair_feed == 0` → 1.0, `1–24` → 0.6,
  `25–99` → 0.3, `≥100` → 0.0
- `DIS` = |대리모델 cyclen − LRM ceiling| 을 해당 열 표준편차로 표준화한 뒤
  `[0,1]` clip. 두 모형이 **가장 크게 어긋나는 곳이 정보량이 가장 큰 곳**
- `REACH` = 실행 가능성. `실현 확인` → 1.0, `격자-우회` → 0.6,
  `미발견`(자산 있음) → 0.8, `실현 불가(격자)` → **0.0 (영구 배제)**
- 가중치 **`w_gap = 0.4, w_dis = 0.4, w_reach = 0.2`** — 여기서 고정.

상위 셀부터 예산 소진까지 취하되 **제약 2건**:
1. 한 e 준위에서 최대 2 셀 (열 편중 방지)
2. e ≥ 5.8 에 **최소 60%** 배분 (지시의 고농축 우선 취지)

### 3c. 체인 설계

- **seed**: 공여자가 있으면 elite-morph (`fr_transfer.pair_mapping` +
  `substitute`, `scoping_mesh.build_elites` 와 동일 기계) — 이것이 지시가 말한
  "engineering rules". 없으면 `pair_feed` 인접 feed 재시작.
- **cap/screen**: LRM ceiling 예상 cyclen 을 상한 기대치로 써서 스크린한다
  (LRM 이 §1d 에서 확증될 경우에 한함; 기각되면 대리모델 기대치로 대체).
- **라이브러리 라우팅**: ga80 과 paramA 는 **분리 deck** 으로 던진다
  (`ProduceDriver._run_library_id` 는 실행당 resolver 1개 — 혼합 deck 은
  paramA 체인이 전멸한다, `feedgrid_pathfinder_20260815.md` §1).
- f125/f129 층에는 `allow_single_cycle_discharge = true` 를 명시한다.

### 3d. 운용 규칙 (기존 상시 규칙 준수)

- **181 은 사용하지 않는다.**
- 199 는 진행 중인 `min_fr` 캠페인이 **끝난 뒤에만** 사용한다. 진행 중인
  f109 캠페인과 autoeng-builder 에이전트 파일(`autoeng.py`,
  `data/reports/autoeng_*`)은 건드리지 않는다.
- 198(유휴)을 탐침 배치의 1차 레인으로 쓴다.
- ship-don't-remote-edit: 원격에서 직접 편집하지 않고 deck 을 실어 보낸다.
- 정규 저장소(`data/store/`)는 harvest 시점까지 **읽기 전용**.
- **재학습은 하지 않는다.** C 의 라벨이 재학습을 정당화하면 *권고만* 보고한다
  (238 은 본 과제에서 쓰지 않는다).

## 5. 무효화 조건 (사전 고정)

- §1d 판정에서 LRM 이 **기각**되면, C 의 cap/screen 기대치를 대리모델로
  바꾸고 그 사실을 결과 보고서에 명시한다.
- 대리모델 메쉬가 고농축에서 Tier-1 가능해를 5셀 이상 보고하면 §2b 경고에
  따라 **외삽 낙관 편향**으로 분류하고, 해당 셀을 앵커 우선순위 최상단으로
  올려 실물로 반증한다.
- 199 캠페인이 예상보다 길어지면 C 는 198 단독으로 축소 집행하고, 미집행
  예산을 **소비하지 않고** 보고한다.
