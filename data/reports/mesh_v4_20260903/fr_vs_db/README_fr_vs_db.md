## 1. 무엇을 비교했나

사용자 요구: *실측 DB에는 F_xy 값이 없으므로 목적함수를 **F_r** 로 두고, 각 조합
(= [노심 평균 농축도, feed 수])에 대해 **F_r · 주기길이 · 방출연소도** 를 비교하고
**그물망 그림 자체**도 비교할 것.*

* **목적함수 (양쪽 동일)** — Tier-1 제한 `F_r ≤ 1.55, F_q ≤ 2.41, CBC_max ≤ 1600 ppm,
  |AO| ≤ 0.30` 을 만족하는 후보 중 **F_r 최소**.
* **F_xy 는 AI·실측 어느 쪽에도 적용하지 않음.** (mesh v4 본편의 `joint_clean`
  은 `F_xy ≤ 1.65` 를 함께 걸었으나, 여기서는 사용자의 요지대로 해제했다. 따라서
  본 폴더의 실측 최적점은 본편 `db_best_*` 컬럼과 값이 다를 수 있다.)
* **AI 측** — `mesh_v4_pareto.csv` 의 각 셀 `rep == "min_f_r"` 점 (새 모델 추론 없음,
  기존 파레토 프런트 재사용).
* **실측 측** — 배포 저장소 `data/store/records.parquet`
  (**76,793 rows**, valid & converged **67,880 rows**,
  sha256 `16E311AF4465E735B38DAF7ABF999268FAC27946C1C5CC279114607D9EE917BA`)
  에서 셀에 속하고 Tier-1 을 통과하는 행 중 **F_r 최소** 행.

### 셀 소속 규칙 (mesh_v4_post.py 그대로 재사용)

```
1차 : (library_id == 셀.library_id) & (case_pair == 셀.pair) & (feed == 셀.feed)
      → db_scope = "pair_feed"
2차 : 1차가 비면 (feed == 셀.feed) & (|e_core − 셀.e_core_pair| ≤ 0.05)
      → db_scope = "ecore_feed_fallback"
3차 : 그래도 비면 "none"
```

25개 셀 전부 **1차(pair_feed)** 로 해결되어 fallback 은 발동하지 않았다.

### 방출연소도

```
B_d = cyclen · P_th / M_HM / 1000 · N_FA / feed      [GWd/tU]
P_th = 3983 MW,  N_FA = 241,  M_HM = 셀의 M_HM_tU (ga80 기준 102.031 tU)
```

AI·실측 모두 **같은 셀의 M_HM_tU** 를 쓰므로 두 값은 직접 비교 가능하다
(즉 ΔB_d 는 Δcyclen 의 상수배).

## 4. 판독

1. **F_r 축에서는 실측 DB가 아직 앞선다.** 양쪽이 존재하는 8쌍 중 6쌍에서 실측 F_r 이
   더 낮고, 평균 ΔF_r = +0.008. 가장 큰 격차는 5.4/113 (+0.053), 5.0/109 (+0.037) 로,
   두 셀 모두 Tier-1 통과 실측 행이 많은 셀(157행, 91행)이다. **탐색량이 곧 F_r 우위**다.
2. **주기길이·방출연소도는 사실상 일치한다.** Δ주기 RMS 5.5 EFPD 이지만 8쌍 중 6쌍이
   |Δ| < 6 EFPD 이고, 큰 두 값(5.0/117 +9.5, 5.2/125 −9.8)은 해당 셀의 Tier-1 실측이
   4행·12행뿐인 데서 온다. ΔB_d 는 정의상 Δ주기의 상수배이므로 같은 이야기다.
3. **AI 그물망은 실측 그물망보다 훨씬 촘촘하다** (그림 A). AI 는 16/25 셀을 채우고
   등feed·등농축도 격자를 형성하지만, 실측은 8/25 셀만 채우고 feed 117·125 두 줄만
   선으로 이어진다. **AI의 값은 개별 셀 최적값보다 미탐색 영역(feed 129, e5.9, 고농축
   × 저feed)에 대한 그물망 확장에 있다.**
4. **핀 연소도 등급**: AI 노드는 red(≥75) 9개 / orange(68–75) 7개. 실측 최적점은
   5.0/109 한 건만 `max_pin_burnup` 라벨이 있고(82.11 → red), 나머지 7개는 저장소에
   값이 없어 미산출(회색 테두리)이다. 등급 비교는 사실상 불가능하다.

## 5. 주의사항 (해석을 바꾸는 것들)

* **AI 노드는 아직 MASTER 로 계산되지 않은 예측 후보다.** 대리모델 s1j 의 예측값이며,
  MASTER 검증 전에는 실측과 같은 지위가 아니다. 반대로 실측 최적점은 지금까지
  **MASTER 로 실제 계산된 것 중 최선**일 뿐, 그 셀의 진짜 최적이 아니다 — 두 값의 차이는
  "모델 오차"가 아니라 "예측 후보 vs 탐색 이력"의 차이다.
* **셀 내 실측 행은 동일 pair/library 이지만 장전패턴은 제각각이다.** 실측 F_r 최소 행과
  실측 최장주기 행은 서로 다른 노심이며(위 표), 어느 쪽도 AI 노드의 장전패턴이 아니다.
* **Tier-1 통과 실측 행 수가 셀마다 0~157 로 극단적으로 다르다.** n=4 인 셀(5.0/117,
  5.2/117)의 Δ 는 통계량이 아니라 단일 표본 차이로 읽어야 한다.
* **F_xy 미적용의 대가.** 본편 mesh v4 는 `F_xy ≤ 1.65` 를 함께 걸었으므로, 여기서 고른
  실측 최적점 중 일부는 F_xy 를 걸면 탈락할 수 있다(라벨이 있는 행에 한해). 인허가
  판단에는 F_xy 게이트를 되살린 본편 표를 함께 볼 것.
* **핀 연소도 등급은 게이트가 아니라 표시 척도**다 (green<62 / yellow 62–68 /
  orange 68–75 / red ≥75). 실제 핀 제한은 80 GWd/tU 이며 이 대조표에서 셀을 닫지 않는다.
* **feed 129 · e5.9 열은 대조 자체가 불가능**하다 (Tier-1 통과 실측 0행). 이 영역의 AI
  값은 외삽이며, MASTER 확인이 선행되어야 한다.
