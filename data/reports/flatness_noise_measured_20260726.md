## 3. 달성 가능 상한 ρ

`ρ_max = s / √(s² + σ²)` — 신호 SD `s`(셀내 실측 SD)와 잡음 SD `σ`에 대해, **완벽한 예측기라도**
잡음 섞인 라벨과의 순위 상관은 이 값을 넘지 못한다. F_r 보고서와 동일한 정의를 쓴다.
`s`는 **셀별 풀드 within-cell SD**(셀 = `folds.cell_key`, `ebin{e}_f{feed}` 또는 캠페인 id,
행 ≥ 8인 셀만)이다.

`ρ_max ≥ 0.95`를 위해 필요한 신호 SD: **node_peak `s ≥ 0.01691`, map_cov `s ≥ 0.00154`.**

## 4. 판정

### 4.1 `map_cov` — **명확: 잡음 병목 아님. 게이트 기준 유지 정당**

- 모든 구간에서 상한 ρ **≥ 0.9947**(CI 상단 기준). 가장 좁은 대역에서도 `s/σ = 11.3`.
- `ρ ≥ 0.95`에 필요한 신호 SD는 0.00154인데 가장 좁은 대역의 실측 `s`가 0.00574 — **3.7배 여유**.
- 현 실측 ρ 0.192와 상한 0.998 사이 간극은 **전부 모델 몫**이다. 게이트 epsilon 0.10은
  도달 가능 순위폭(1−0.998 ≈ 0.002 손실)에 비해 충분히 크므로 **분해 가능한 차이를 판정한다**.
- **F_r형 "원리적 한계" 구간 없음.**

### 4.2 `node_peak` — **대체로 유지 정당, 최심층 평탄대 1칸만 미해결**

- 전역·평탄 1/3까지는 상한 0.992–0.998로 여유롭다.
- `node_peak ≤ 1.394` 대역만 상한이 **0.947(저장소) / 0.973(fold C)**, σ 불확실성을 태우면
  **0.898–0.951** — `FR_GUARD_MIN_LABEL_CEILING = 0.95` 기준선을 **걸친다**.
- 원인은 물리적으로 명확하다: 잡음이 **중심 슬롯에 집중**(σ 0.0072)되고 `node_peak`은 최대값이라
  그 최악 슬롯을 상속한다. 평탄한 노심일수록 신호 SD `s`가 작아지므로 비가 나빠진다.
- **단, 이것이 오늘 게이트를 무력화하지는 않는다.** 게이트가 채점하는 대역은 전체 홀드아웃이지
  `≤1.394` 층이 아니고, 그 대역의 상한은 0.9997이다.
- 완화책(관측): `node_peak`의 **피크 위치는 22/22 완전 재현**된다. 위치·상위 k 슬롯 집합 같은
  이산 지표는 이 잡음을 받지 않으므로, 최심층 평탄대에서 `node_peak` 값 순위 대신
  **"피크가 어디에 서는가"** 로 목표를 재정의하면 잡음 바닥을 우회할 수 있다.

### 4.3 ★게이트가 두 축을 **채점할 수 없다** — 오늘의 진짜 병목

`gate_no_regression`은 done 셀의 **셀별 curriculum-val 홀드아웃**에서 저장된 진리값
(`node_peak` / `map_cov` 컬럼)으로 채점한다(`score_no_regression_cell`). 그 슬라이스를 전수 조사했다:

| 항목 | 값 |
|---|---:|
| 게이트 슬라이스 셀 수 | 36 |
| 수렴행 | 1,494 |
| `cyclen` 라벨 보유 | **1,494** |
| **`node_peak` 라벨 보유** | **0** |
| **`map_cov` 라벨 보유** | **0** |
| **`maps_key` 보유(맵 자체)** | **0** |
| 맵 라벨 ≥3행인 셀 | **0 / 36** |

(행 데이터: `flatness_noise_measured_20260726_gate_slice_by_cell.csv`)

맵 라벨의 실제 소재: **train 26,080 / fold C 2,262 / fold B 1,512 / fold A(게이트 슬라이스) 0.**
fold A 1,494행은 전부 dataset P(커리큘럼)이고 `harvest_maps`가 켜지기 전에 생산되어 **맵 자체가 없다**
(`maps_key` 전부 null → `backfill_flatness`로도 복구 불가, MASTER 재실행이 필요).

**귀결**: `NOREG_ENFORCED_DEFAULT`가 `("cyclen","node_peak","map_cov")`이지만, 두 평탄도 축은 매 셀
`unavailable: "fewer than 3 rows carry a node_peak label"`로 떨어지고,
`ok = all(c["drop"] <= eps for c in checks if enforced and drop is not None)`는 **빈 집합 위의 all → True**.
즉 **오늘 실제로 거부권을 행사하는 축은 `cyclen` 하나**다. `unavailable` note가 이를 출력하므로
은폐는 아니지만, "평탄도 축이 거부권을 진다"는 설계 의도는 **실행되지 않고 있다**.

부가 확인: 신규 셀 스킬 게이트(`_gate_newcell`)의 `PROBE_TARGETS`에는 `node_peak`/`map_cov`가
**아예 없다**. 오프라인 A/B(`ab_eval.no_regression_gate`)의 기본 targets도 `("cyclen","f_r")`이며,
M6 확장이 계획으로만 남아 있다. 이 표면은 fold C(맵 2,262행)를 읽으므로 **즉시 채점 가능**하다.

## 6. 권고

### R1. **게이트 기준(epsilon·거부권 구성)은 조정하지 마라.** (잡음 근거로는)

`node_peak`/`map_cov`는 F_r과 **다르다.** 두 축의 상한 ρ는 결정 구간에서도 0.99 안팎이고,
`gate_noreg_epsilon = 0.10`은 라벨 잡음이 강요하는 결손(node_peak 평탄 1/3에서 0.002,
map_cov에서 0.0002)보다 **50~500배 크다**. 게이트는 자신이 **분해할 수 있는 차이를 판정하고 있다**.
F_r 강등의 논거(상한 0.839 < epsilon이 전제하는 분해능)는 여기서 성립하지 않으므로
**두 축을 guarded로 유지하는 것이 옳다.**

### R2. **★최우선 — 게이트 슬라이스에 맵 라벨을 공급하라.** (라벨 문제이지 잡음 문제가 아니다)

오늘 두 축의 거부권은 **선언만 되어 있고 실행되지 않는다**(§4.3, 0/1,494행). 선택지:

| 선택지 | 내용 | 비용 | 비고 |
|---|---|---|---|
| **(i) 권장** | 오프라인 A/B `ab_eval.no_regression_gate`의 targets를 **M6 계획대로 `("cyclen","node_peak","map_cov")`로 확장** | **0 MASTER 콜** | fold C에 맵 2,262행 / 46셀이 이미 있다. 즉시 실행 가능한 유일한 채점 표면 |
| (ii) | 커리큘럼 val 홀드아웃을 `harvest_maps=1`로 재생산 | 1,494 콜 | 근본 해결이지만 비싸다 |
| (iii) | 다음 `make_curriculum_split` 재구성 시 **맵 보유 행을 val 홀드아웃에 우선 배정** | 0 콜 | 점진적, (ii)의 저비용 대안 |
| (iv) | `gate_no_regression`이 `unavailable`인 enforced 축을 **PASS가 아니라 판정 보류**로 다루도록 의미론 명시 | 코드 | 빈 집합 위의 `all()`이 PASS를 만드는 현 구조를 명시적 상태로 |

(iv)는 정직성 문제다 — 현재도 `note`에 "These axes were NOT verified regression-free"가 나가지만,
`pass=True`가 함께 나가므로 자동 파이프라인은 통과로 읽는다.

### R3. `node_peak ≤ 1.394` 대역만 **표적 재측정**(60 MASTER 콜, 승인 필요)

전치쌍 프로토콜을 그대로 쓰되 `pick_pairs`의 표본을 `node_peak ≤ 1.394` 행으로 층화 추출한다.
판정 기준은 `σ ≤ 0.00762`(= fold C `s`/3.043). **이 재측정 전까지는 최심층 평탄대에서
`node_peak` 값 순위를 기준으로 모델을 기각하지 마라** — F_r에서 저지른 실수의 재발 지점이 바로 여기다.
`map_cov`는 재측정 없이 지금 게이트해도 된다.

### R4. 상수·문서 정정 4건

| 대상 | 현재 | 정정 |
|---|---|---|
| `curriculum.FR_GUARD_MIN_LABEL_CEILING` 주석 (ii) | "k회 반복평균으로 σ 1/√k 축소, k ≥ 4 필요" | **반복은 비트 동일 → 무효. 대칭 평균만 유효하며 k ≤ 2** (§2.1) |
| `flatness_noise_floor_20260725.json` `map_cov` | σ = 0.000586 (비가중 CoV) | **σ = 0.000507 (정규 가중 CoV)** (§1.4) |
| `transpose_noise_measured_20260725.md` §4 | "node_peak/map_cov 측정 불가" | **본 보고서로 측정 완료(추가 콜 0)** |
| 잡음의 성격 | "솔버 수렴·메시·restart 부기" | **순수 표현 잡음**(동일 덱 반복 σ = 0, 46/46 바이트 일치) |

### R5. 모델 개선의 방향은 바뀌지 않는다

평탄층 성능 붕괴(CoV ρ 0.192 / peak ρ 0.101)는 **라벨 분해능이 아니라 모델 문제**임이 확정됐다.
따라서 `cyclen_nodepeak_resolution_20260725.md` §2.6의 처방(**셀별 상수 오프셋 보정**,
`map_calibration.json`)은 여전히 유효한 최우선 회수 수단이고, 그 위에 §3.8의 분해능 처방을 얹으면 된다.
"라벨을 더 정밀하게 만들어야 한다"는 F_r식 결론은 **이 두 축에는 적용되지 않는다.**
