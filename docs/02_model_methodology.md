# 02. 모델 방법론 — PosValNet: 집합체 표현과 평형주기 결과인자 예측

> **이 문서의 위치.** `lpopt`의 궁극 목표는 예측이 아니라 **"최적 노심을 장전하는 규칙 자체를
> 학습한 노심 엔지니어 AI"**다. 이 문서는 그 기반이 되는 두 가지 — ① 집합체(FA)를 무엇으로
> 표현할 것인가, ② 그 표현 위에서 평형주기 주요 결과인자를 어떻게 예측할 것인가 — 의 방법론
> 전체를 다룬다. 탐색·캠페인·정책 학습은 별도 문서의 몫이다.
>
> **정직성 규약.** 본문의 모든 수치는 저장소의 실측 보고서에서 인용하며 **측정 일자를 병기**한다.
> 근거 문서가 없는 서술은 `(추정)`으로 표시한다. 실패한 실험과 기각된 가설도 성공과 같은
> 비중으로 기록한다 — 이 프로젝트에서 가장 값비싼 자산은 "무엇이 통하지 않는지"의 목록이다.
>
> **2026-08-31 개정.** 목적축이 `F_r` → **`F_xy`** 로 바뀌면서(2026-08-29 사용자 확정) 이
> 문서에 세 덩어리가 들어왔다: **`f_xy` 9번째 타깃과 헤드 arm 1→3 판정**(§6.8),
> **서빙 경로 피처화 결함과 보정 재적합 18/18**(§5.6–5.7), **11대 챔피언 `s1j`**(§7).
> §6.1의 결론 — 노이즈 바닥을 넘는 일반 정확도 개선은 v6 → v6b 한 번뿐 — 은 **바뀌지
> 않았다**.

## 1. 문제 정의

### 1.1 입력

하나의 학습 표본 = **하나의 평형주기 장전모형(LP)** 이다.

| 입력 | 형식 | 설명 |
|---|---|---|
| 장전 패턴 | 1/4 대칭 노심의 **69 슬롯** 배치 | APR1400 17×17 노심(241 집합체)의 사분면 표현. 각 슬롯에 (집합체 타입 또는 셔플 소스 좌표 + 회전) 지정 |
| 집합체 대칭 | 집합체 자체는 **1/8 대칭** 설계 | 설계규칙 R2 (2026-07-24 확정) |
| 노심 평균 농축도 `e_core` | 스칼라 [w/o] | 현 코퍼스 범위 5.0 – 6.5 |
| feed 수 | 정수 | 신연료 집합체 수. **유효 격자는 1+4N만** (짝수·중앙 비-fresh 배치 불가) → 101, 105, 109, 113, 117, 121, 125, 129, 133, 137, 141 |
| 라이브러리 | 범주 | `ga80` / `paramA` / `260624` / `5.8_5.1` / `legacy_a` — 집합체 타입 사전 |

패턴은 **19×19 격자**(17×17 노심 + 1셀 반사체 링)로 인코딩된다. 사분면 69슬롯은 4중 미러
전개로 전노심에 펼쳐지고, 헤드는 슬롯 반복도 `w_i`(대각 4, 축상 2, 중앙 1, Σw = 241)로
가중된 평균·최대 풀링을 읽는다 (`lpopt/model/net.py`, `featurize.py`).

라벨은 결정론적 노심해석 코드 **MASTER**의 평형주기 수렴 결과다. 평형 판정은 5개 FOM의
연속 사이클 절대 허용오차(cyclen 0.10 EFPD, cbc_max 1.0 ppm, f_q/f_r/ao 각 1.0e-3)를
`consecutive=2`로 통과할 때이며, 이것이 라벨 잡음의 물리적 하한을 정한다 (§6.3).

> **★정정 (2026-08-29).** `lpopt/data/flatness.py`는 모듈 docstring과 코드 주석 두 곳에서
> `node_peak == F_xy`라고 **단언하고 있었다. 틀렸다.** `node_peak`은 EDIT5 BOC **집합체**
> 출력맵의 최댓값이고 `F_xy`는 MASTER `FXYP` = **핀 평면** 첨두로 서로 다른 물리량이다.
> 실측 상관은 0.735–0.854, 잔차 sd 0.057–0.064, 최대 잔차 0.25 — **대리 불가**다. 이 오기는
> `F_xy` 전환 설계서 §3.10에서 P1 필수 항목으로 격상되어 정정되었다. 실무 귀결:
> `flat_power` 모드는 평탄한 패턴이라는 이유로 `F_xy`를 보증하지 못하므로 별도의
> `flatpower_fxy_limit` 안전게이트를 받았다.

**`F_xy`와 `F_r`의 실측 관계** (HOST_199 `MAS_OUT` 192 노심, 2셀, 2026-08-29):
`F_r ≤ F_xy ≤ F_q`가 **192/192에서 성립**하고 비는 `F_xy/F_r = 1.0694 ± 0.0181`
(p05 1.0351 / p95 1.0934), 풀드 선형은 `F_xy = 1.1221·F_r − 0.0831`(r 0.9505, 잔차 sd
0.0293)이다. **그러나 한계 게이트는 대체되지 않는다** — `E1_E2/f109` 94행에서 `F_r ≤ 1.55`를
통과한 52개 중 **18개(34.6%)가 `F_xy ≤ 1.65`에서 탈락**한다(`N1_N2/f113`은 0개,
regen `T6_T4/f121` 690행은 41개). 셀 의존적이라 어느 축도 다른 축을 함의하지 않는다.
`F_q/F_xy = 1.1586 ± 0.0218`이므로 `F_xy ≤ 1.65`는 `F_q ≈ 1.91`을 함의한다 — **2.41보다
훨씬 빡빡한 게이트**다.

`node_peak` / `map_cov`의 **가중(multiplicity-weighted) 정의**는 `lpopt/data/flatness.py`에
단일 정의로 두고 `ab_score`/`verify`/`dataset_torch`/`model_api`/백필이 전부 import한다
(2026-07-25 변경 C2). 비가중 정의는 분모(69슬롯 단순평균)가 레코드마다 0.983–1.088로
최대 10% 흔들려 **물리량으로 보고할 수 없다**. 가중평균은 실측 0.9999–1.0001로 정확히 1.0이다.

### 1.3 어려움의 소재 — 전역 ρ가 아니라 셀내 ρ

탐색이 실제로 소비하는 능력은 **같은 설계 조건 안에서 후보의 순위를 가르는 능력**이다.
따라서 1차 지표는 `campaign × case_pair × feed`로 정의한 **iso군 내 Spearman ρ**이고,
전역 ρ는 셀 간 스케일 차이로 부풀려진다.

> 2026-07-25 실측: fold A에서 cyclen 전역 ρ **0.997** vs 셀내 중앙 ρ **0.806**.
> 2026-07-29 실측: cyclen 전역 0.998 vs iso ρ **0.755**.
> 셀 라벨만 알아도 전역 ρ 0.99가 나온다 (fold A는 cyclen 522–890 EFPD, CBC 1,010–3,810 ppm에 분포).

**전역 ρ만 인용하면 성능이 과장된다** — 이 문서의 모든 헤드라인 수치는 iso/셀내 ρ이다.

## 2. 집합체(FA) 표현 — 핵심 설계 결정

### 2.1 주 피처 = 결과값 (행동 서명)

> **결정 (2026-07-18, 사용자 확정).** 집합체 표현의 **주 피처는 설계 제원이 아니라
> 격자 계산의 결과값**이다 — `FA_*.sum` / `FA_*.HGC`가 내놓는 k-inf(BU) 곡선 특성점,
> 2군 단면적, 핀 form function 최대치, ADF. `dec_FA_*.inp`의 설계축(zoning 농축도, Gd 제원)은
> **보조 피처·폴백**이다.

근거: 결과값은 **임의의 가연성독봉·설계제원에 자동 일반화되는 행동 서명**이다. 새 집합체가
들어오면 `fuel_types` 테이블에 한 행을 추가하는 것만으로 모델이 그것을 읽을 수 있다.
2026-08-09 감사에서 확인: 코드베이스 전체에 `nn.Embedding` / one-hot 연료 정체성 **0건**.

### 2.3 k-inf(BU) 곡선 형상 9채널 — 보편 독봉 서명

`lpopt/data/fuel_types.py::kconv_curve_shape`가 참조 k-inf(BU) 감손곡선을 반응도 공간
`ρ = (k−1)/k × 1e5` [pcm]에서 읽어 9개 형상 특성점을 뽑는다 (2026-07-20 수확).

| 컬럼 | 단위 | 의미 |
|---|---|---|
| `kinf_dip` / `bu_dip_gwd` | – / GWd/tU | 억제 골(trough)의 k-inf와 연소도 |
| `kinf_peak` / `bu_peak_gwd` | – / GWd/tU | 소진 hump 최대점 (독봉 완전소진) |
| `reactivity_swing_pcm` | pcm | `ρ_peak − ρ_dip` — **홀드다운 방출 크기** |
| `rho_boc_minus_peak_pcm` | pcm | `ρ(0) − ρ_peak` — 초기 억제 깊이 (부호 있음) |
| `depletion_slope_pcm_per_gwd` | pcm/GWd | `bu_peak..min(60, last)` 구간 최소자승 `dρ/dBU` |
| `kinf_eol50` | – | 50 GWd/tU 보간 k-inf (방출 반응도) |
| `kconv_is_monotone` | 플래그 | hump 부재(약독봉 설계) = 1.0 |

실측 분포 (2026-07-20, 153행 중 곡선 보유 117행 / hump 보유 92행):
`reactivity_swing_pcm` 9.0 – 1,047 – 5,198 pcm (min–median–max), `depletion_slope` −651 – −600 – −340 pcm/GWd,
`bu_peak_gwd` 0 – 19 – 25 GWd/tU, `kinf_eol50` 0.927 – 0.957 – 1.007.

물리 정합성 확인(`tests/test_fuel_kconv_shape.py`): 강-Gd 10wt%/20pin은 dip 1.1144 < peak 1.1238,
swing +755 pcm, slope −600 pcm/GWd. 약-Gd 6wt%/12pin은 `kconv_is_monotone=1`로 우아하게 축퇴.
`.sum` vs HGC 파리티: `bu_dip`/`bu_peak` 동일, k값 <1e-4, swing <0.4 pcm, slope <0.003 pcm/GWd.

### 2.4 독봉 불가지론 (poison-agnostic)

> **지시 (2026-07-20, 사용자).** 학습 채널에서 독봉 특정 축을 **제외**한다 —
> 셀 채널 `origin_n_gd` / `origin_gd_wt` / `origin_gd_u_enr`, 전역 `g_fresh_mean_n_gd` /
> `g_fresh_mean_gd_wt`. 미래의 IFBA / Er / Dy 대응을 위해 **k-conv 곡선 형상이 보편 독봉
> 서명을 담당**한다.

이유: 곡선 형상은 *그것을 만든 독봉 설계*가 아니라 *곡선의 모양*을 기술하므로, 오늘의 Gd 격자에도
내일의 IFBA / Er / Dy 집합체에도 동일한 dip/hump/swing/slope 서술자가 적용된다.
`fuel_types` 테이블의 Gd 컬럼은 QC·부기용으로 **보존**한다 — 삭제되는 것은 *모델 채널 선택*뿐이다.

OOD 가드도 이 결정의 수혜자다: 독봉 축이 `n_gd`/`gd_wt` 경계가 아니라 **형상 피처 포락선**으로
표현되므로, 낯선 swing/slope/hump 타이밍을 가진 임의 화학종의 흡수체가 포락선을 건드린다.

**어블레이션 검증** (2026-07-21, v5 통합 A/B 5-arm):

| arm | cyclen 셀내 ρ | cyclen MAE [EFPD] | F_r 셀내 ρ | F_r MAE |
|---|---:|---:|---:|---:|
| v4_baseline | 0.7798 | 5.846 | 0.9042 | 0.1434 |
| v5_full | 0.7519 | 5.206 | 0.8989 | 0.1450 |
| **v5_minus_shape** | 0.7513 | **6.565** | 0.8984 | 0.1414 |
| v5_distill | 0.7553 | 5.032 | 0.8972 | 0.1410 |
| **v5_distill_w160 (채택)** | **0.7666** | 5.215 | **0.9016** | **0.1402** |

형상 채널을 뺀 `v5_minus_shape`가 cyclen MAE에서 유일하게 크게 후퇴(6.565)한다 —
**형상 채널이 실재 신호를 담고 있음**의 어블레이션 증거.

**남은 미검증 항목 (F5, 2026-07-21 적대적 검토):** 코퍼스가 전부 Gd 독봉이므로 "타 독봉으로의
전이"는 현 데이터로 검증 불가하다. 어블레이션은 *신호 존재*만 입증했다. 비-Gd 1종 실증은
커리큘럼 완주 후 과제로 등록되어 있다.

### 2.5 identity 임베딩 금지

연료 타입 정체성을 임베딩하면 새 집합체마다 재학습이 필요하고, 표현이 "행동"이 아니라 "이름"을

|---|---:|---:|---:|
| BASE (구조 + 라이브러리/쌍 one-hot) | 0.7142 | 0.8023 | 0.0519 |

### 2.6 연소도 배치 — `NOMINAL_CYCLE_BURNUP` → 레짐 테이블 (v6b)

v6까지 연소 슬롯의 a-priori 연소도는 단일 상수 `NOMINAL_CYCLE_BURNUP_MWD_KG = 22.0`로

2026-08-09 실측 (12,174 궤적 코어): 연소 슬롯 배치 오차 평균 **12.18 GWd/tU** =

전체 코어의 **45.8%**에서 연료 스왑 1회의 효과 전체를 초과한다.
그리고 오차는 `(library_id, feed)`에서 **계통적**인데, 그 둘은 이미 모델 입력이다

### 2.9 집합체 표현은 충분통계인가 — H2/H4 널테스트

> **명제 P1.** (k-inf(BU) 곡선, 농축도)가 집합체의 (준)충분통계다.

**반례가 실측되었다 (2026-08-09~10).** `ga80` 라이브러리의 **H2 vs H4**:
농축도 동일(5.5 w/o), Gd봉 24개 동일, k-곡선이 전 연소점에서 **57~71 pcm 이내** 일치.
그런데 `adf_face_g2`가 **3.2%(0.0351)** 다르고 `ff_pin_max` 0.028, `cr1_worth` 631 pcm 차이.
P1이 참이라면 두 집합체는 구분 불가여야 하는데, **MASTER 실측 노심 ΔF_r = 0.0351**
(음성대조 0.0005). → **(k곡선 + 농축도)는 충분통계가 아니다.**

**두 번째 특성은 농축도가 아니라 ADF다.** 동일 프로토콜 회귀 기여:

| 추가 특징 | node_peak R² 기여 | 비고 |
|---|---:|---|
| 농축도 (+ENR) | **+0.0058** | 사실상 없음 |
| k-곡선 (+KCURVE) | +0.0374 | |
| **ADF 단독** | **+0.0305** | k-곡선 이득의 74%를 단독으로 |

물리적 이유: `ga80`에서 R²(`adf_face_g2` | 10열 k-곡선) = **0.003**(농축도를 더해도 0.002).
반면 M² 0.998, MTC 0.991, 붕소가 0.991, 도플러 0.993 — **ADF만 k-곡선에 붕괴하지 않는다.**

**그러나 face-ADF 채널 추가(v6c)는 해로웠다 (2026-08-10 A/B).**

| 항목 | 결과 |
|---|---|
| 게이트 1차 (`T_cell_mae_node_peak`) | 점추정 **−0.014444**, CI [−0.019349, −0.011120] → **FAIL** |
| 유해 위반 | `T_cell_mae_cyclen` −0.3000 (ε 0.10), `M2_flat_tercile_rho_node_peak` −0.0460, `M2_flat_tercile_rho_map_cov` −0.0527 |
| 판정 | **REJECT** — 5개 축이 established-worse, 승격 안 됨 |

**원인은 사전등록 단계에서 이미 예고되어 있었다.** ADF 가설의 유효 성분
(`origin_adf_corner_g2` idx 38, `origin_cr1_worth` 34, `origin_ff_pin_max` 30)은
**v4부터 이미 입력에 있었고**, 대조군이 H2/H4 판별을 이미 통과했다 (예측 +0.0069 vs 실측 +0.0072).
즉 널테스트의 "ADF가 두 번째 특성" 결론은 **기존 채널로 이미 충족된 상태**였고,
face-ADF를 더하는 것은 순수 추가 해악이었다.

**운용 수준 반증도 함께 기록한다 (2026-08-09).** 고정 패턴에서 연료만 스왑했을 때의
Δnode_peak 변화 예측: 부호 적중 **0/8**, Spearman **−0.214**. 그리고 챔피언은 24패턴 전이
스윕에서 소스→타깃 node_peak 상관을 **+0.803**으로 주장하지만 MASTER 실측은 **−0.036**이다 —
**전이되지 않는 바로 그 지점에서 전이를 확신한다.** 반면 고정 연료에서 패턴을 랭킹하는 능력
(= LP 최적화기가 실제로 하는 일)은 k-곡선 추가로 0.8043 → 0.8046 (**+0.0003**)뿐이다.
결론: **k-곡선이 개선하는 축은 탐색이 쓰지 않는 축이다.**

### 3.1 전체 구성

```
cells [B, 62, 19, 19] ──> stem(Conv3x3 → W)
                            │
                            ├─ ResidualBlock × 8   (GroupNorm(8) → SiLU → Conv3×3, ×2, + skip)
                            │    └─ FiLM(globals) 주입 every 2 blocks
                            │
      globals [B, 20] ──────┘
                            │
        ┌───────────────────┴─────────────────────────────┐
        │ 탭 (stem, blk2, blk4, blk7)                      │  (멀티스케일 맵 경로)
        │  → MultiScaleMapDecoder                          │
        │     concat(4W) → Conv3×3(d=1) → Conv3×3(d=2) → 1×1 → 4 plane
        │  → + prior_power 스킵 (map_prior_gain[0]=1 초기화)
        │  → SE 셀 gather → 9×9 사분면 맵                   │
        └──────────────────────────────────────────────────┘

                            │
```

### 3.2 하이퍼파라미터 (챔피언 `s1i`, 2026-08-17)

`net_config`·best epoch)이며 **pickle된 클래스 없음**이 이식성 규칙이다.

### 3.3 손실 구성

`_step_member` (`lpopt/model/train.py`)가 조립하는 총 손실:

```
loss = loss_reg                                     # Huberized Gaussian NLL (β-NLL 0.5, huber δ 1.0)
     + map_lambda(0.3)          * loss_map          # 맵 Huber (map_peak_weight 2.0로 피크 가중)
     + conv_weight(1.0)         * loss_conv         # 수렴 여부 BCE
     + map_spectral_weight(0.3) * spectral_map_loss # 대역가중 2-D FFT 손실 (5 반경대역, 고주파 ×4)
     + cyclen_rank_weight(0.1)  * cyclen_rank_loss  # 셀내 pairwise 힌지 (margin_z 0.1, min_gap 2.0 EFPD)
     + f_r_rank_weight(0.1)     * f_r_rank_loss     # 동일, min_gap 0.01, F_r<1.7 구간 가중 ×3
     + distill_weight(0.4)      * loss_kd           # soft-target 증류 (Huber)
     + quantile_weight(0.2)     * pinball_loss      # 다분위 pinball
```

(`traj_weight` / `axial_weight` / `map_fr_consistency_weight` / `map_peak_topk_weight`는 현재 0 —
전자 둘은 미착수 축, 후자 둘은 A/B에서 기각.)

**용어 주의.** "국소 대비(local contrast)"는 **손실 항이 아니라 입력 채널 패밀리**
(`origin_kinf_contrast`, `origin_age_contrast`, `prior_power_contrast`)이고, 구조적 대응물은
멀티스케일 디코더의 dilation-1 / dilation-2 혼합 컨볼루션이다. 맵 쪽 손실 노브는
`map_peak_weight`(연속 재가중 `1 + w·relu(map_z)`), `map_peak_topk_weight`(라벨 기준 상위 K 슬롯),
`map_spectral_weight` **셋뿐**이다.

**스펙트럼 손실 대역** (`_SPECTRAL_BANDS`, 9×9 사분면 평균제거 마스크드 2-D FFT, DC 가중 0):
파수 k = 0.00–0.13 → 1.0, 0.13–0.25 → 1.0, 0.25–0.36 → 2.0, **0.36–0.47 → 4.0,
0.47–1.00 → 4.0**. 진폭뿐 아니라 **위상**도 벌한다 (`diff.real² + diff.imag²`).

**랭크 손실의 존재 이유** (2026-07-20 사용자 인터뷰 채택 항목 ①): 회귀 손실은 z-압축에
취약해 셀 안에서 예측을 상수처럼 뭉갠다. 셀내 ordered-pair 힌지는 **z-압축 면역**이며
탐색이 실제로 소비하는 축(순위)을 직접 최적화한다.

### 3.4 물리 프라이어 잔차학습 — cyclen

cyclen을 직접 회귀하는 대신 **닫힌 형태의 0차원 반응도 수지 추정치에 대한 잔차**를 학습한다
(`lpopt/model/physics_prior.py`, v5 번들).

69 슬롯 각각에 대해 셔플 사슬을 fresh 기원까지 추적하고 그 기원의 수확 곡선을 읽어:

```
ρ_j(b) = ρ_j* + s_j (b − bu_j*)              b ≥ bu_j*   (소진 감쇠)
ρ_j(b) = ρ_j* − S_j (1 − b / bu_j*)          b <  bu_j*   (홀드다운 방출)

b_j     = bu_j0 + NOMINAL/2                              (a-priori 중간주기점)
ρ̄       = Σ w_j ρ_j(b_j) / Σ w_j             [pcm]
D       = − Σ w_j s_j / Σ w_j                [pcm/GWd] > 0
B_cycle = (ρ̄ − RHO_LEAK) / D                 [GWd/tU]
cyclen_prior = α · B_cycle + β                [EFPD]
```

`ρ_j*` = `kinf_peak` 반응도, `s_j` = `depletion_slope_pcm_per_gwd`, `S_j` = `reactivity_swing_pcm`.
`RHO_LEAK` = 3500 pcm 고정. `(α, β)`는 **train 스플릿에서만** 최소자승으로 적합하는 2개 스칼라이며
셀별이 아니므로 셀별 라벨 정보를 세탁할 수 없다. 챔피언 `s1i`: α = 10.356, β = 602.054,
n_fit 53,577, Pearson 0.872 / Spearman 0.887.

**정직한 한계:** 프라이어 **단독**의 셀내 ρ는 **0.064 [−0.005, 0.172]** — 통계적으로 0이고
MAE 21.75 EFPD다 (2026-07-25 실측). 잔차 학습 후 0.726에 도달하므로
**셀내 변별력의 100%는 신경 잔차 헤드에서 온다.** 프라이어가 사는 것은 밴드 간 편향 구조
제거와 저농축 외삽 기반이다.

> **서빙 함정 (반드시 기억).** 물리 프라이어 되더하기는 `model_api.py`의 `_ensemble_raw`
> 경로 **안에만** 있다 (`mean_t[:, cyclen_idx] += prior_vals`). raw 헤드를 그대로 채점하면
> 모든 cyclen 수치가 조용히 틀린다. 2026-08-15 스케일링 실험과 2026-08-16 계보 재서빙은
> 이 때문에 **serve 경로만** 사용했다.

### 3.5 확산 출력프라이어 잔차 — 맵

`lpopt/model/power_prior.py`가 스칼라 프라이어의 **공간판**을 제공한다: 동일한 수확 k-곡선으로
집합체별 `kinf_j`를 만들고, 사분면을 17×17(241 노드)로 미러 전개해 **1군 조대격자 확산
고유치 문제**를 푼다.

```
A φ = (1/k) (h²/M²) kinf φ ,     h = 20.78 cm (집합체 피치)
A = 5점 라플라시안 + h²/M² + 연료 밖을 보는 면마다 외삽경계항 1/extrap
P_j ∝ kinf_j · φ_j ,  전노심 평균 1로 정규화 후 사분면 접기
```

학습 파라미터 **0개**, 자유 파라미터는 `(M², extrap)` **2개 전역**뿐이며 train 스플릿에서만 적합.
챔피언 서빙값은 `(M², extrap) = (150.0, 2.0)` (`power_prior.json`, `s1i`: n_fit 3,997,
셀내 ρ 0.671). 출력은 `edit5._quadrant`가 `boc_power` 라벨을 쓰는 **바로 그 69슬롯 격자**이므로
`label = prior + residual`이 정확한 왕복이 된다.

**채택 근거는 스펙트럼 상보성이다** (2026-07-25 실측). 반경 파수 대역별:

| 대역 (저→고) | CNN 모드-ρ | 프라이어 모드-ρ |
|---|---:|---:|
| k1 | 0.897 | 0.545 |
| k2 | 0.877 | 0.721 |
| k3 | 0.785 | 0.712 |
| k4 | 0.717 | 0.773 |
| k5 (나이퀴스트) | **0.593** | **0.861** |
| 나이퀴스트 파워비 | 0.713 | **0.862** |

CNN은 파수가 오를수록 단조 **하락**하고 프라이어는 단조 **상승**한다. 프라이어의 고파수 성분은
셔플이 만드는 국소 k-inf 대비에서 직접 오고, 저파수 오차는 조잡한 집중 누설에서 온다 —
**두 오차 구조가 상보적**이므로 분해가 각 성분을 강한 곳에 배치한다.

맵 헤드의 프라이어 게인은 `gain[0] = 1.0`(boc_power만 통과)으로 초기화되어, **스텝 0에서
맵 예측 = 확산 프라이어**다. 즉 학습이 트렁크가 감쇠시키는 고파수 성분을 이미 가진 해에서 출발한다.

**정직한 반증도 기록되어 있다:** 프라이어 **단독**은 붕괴 구간에서 챔피언보다 나쁘다 —
이미 평탄한 하위 1/3에서 CoV 쌍부호적중 0.570 (챔피언 0.692), 예리한 1/3의 peak 0.484 (0.757).

### 4.4 정직 게이트 (honest gate)

**교훈의 출처 (2026-07-18 포렌식).** 셀 4(`5-5.25_f117`) 게이트가 연쇄 실패한 진범은

(a) 재학습마다 `make_splits`를 재생성했고 seed-0에서 조상폐포 union-find가 커리큘럼 전 셀을

이라는 불공정 비교였다.

**수정된 계약:** 두 모델을 **동일 홀드아웃 행에 라이브 채점**하고,
`drop = ρ_champion − ρ_candidate`가 어떤 (셀, 타깃)에서도 ε를 넘으면 FAIL.

**ε 재보정 (2026-07-18).** n=30 홀드아웃에서 null SD σ₀ ≈ 0.042, 셀내 (cyclen, f_r) drop 상관 ≈ 0.01

family-wise 5%를 위해서는 ε ≈ **0.101**(개별 ≈ 0.069)이 필요하다. → ε를 0.05 → **0.10**으로 상향,
커리큘럼 셀 가중 캡 8 → 16.

### 5.3 셀 보정 (cell calibration)

챔피언의 cyclen 헤드는 정직 홀드아웃에서 **셀별 균일 편향**(+6.6 ~ +14.7 EFPD 과대예측)을
갖는다. 원인: 전역 z-스코어 Huber/NLL 손실이 ~38k feed-121 코퍼스에 지배되어 셀-조건부 평균을
Dataset-A 레짐 쪽으로 수축시킨다. 편향은 `(feed, e_core-bin)` 셀당 거의 상수 시프트이고,
편향 중심화하면 셀별 MAE가 MASTER 수렴 잡음 바닥(~2 EFPD)까지 붕괴한다.

**Stage 1 — 서브측 셀별 affine.** `cyclen_cal = a·pred + b`를 챔피언 **자신의 train 행**에서만
로버스트 적합 (홀드아웃은 절대 건드리지 않음). `cell_calibration.json` / `f_r_calibration.json` /
`cbc_calibration.json` 3개 독립 파일, 각각 disjoint 컬럼을 건드리며 **부재 시 완전한 no-op**.
2026-07-21부터 `auto_fit_cell_calibration = true`로 **재학습마다 자동 적합** — 그 이전 챔피언들이
무보정 서빙이던 결함의 수리다.

셀 키는 `cyclen_cell_key(feed, e_core, bin_width=0.05)`이며 `compute_cell_weights` 정의에서
dataset 축만 뺀 것이다. 아핀 vs 순수 시프트는 **5-fold 교차적합**으로 고른다.
문턱 `min_rows 30` / `slope_min_rows 50` / `prior_weight 4.0`; 채택 마진 cyclen 0.25 EFPD,
F_r 0.006, CBC 2.0 ppm, F_q 0.008, AO 2.0e-4. `serve_parity_mask`가 적합/서빙 간 `e_core`
라이브러리 해석 파리티를 지킨다. 여섯 번째 아티팩트 `flatness_calibration.json`은
`node_peak`/`map_cov` 절편 보정이다.

**Stage 2 — 캠페인 러닝 편향.** Stage 1 보정이 없는 신규 셀에서는
`bias_hat = n/(n+prior) · median(pred − actual)`을 이 캠페인의 MASTER 검증 체인에서 누적해 뺀다.
검증 라벨이 도착하기 전까지는 완전 무해(0), Stage 1이 덮은 셀은 절대 건드리지 않는다(이중보정 방지).

**맵 헤드 레벨 보정 (`lpopt/data/map_calibration.py`).** `node_peak`/`map_cov`/`f_r`의 셀별 편향
(`bias = median(pred − actual)`)을 `map_calibration.json`에 두고 `pred − bias`로 교정한다.
파생 게이트량은 **오직 조이는 방향으로만** 클램프된다:
`fr_bias = max(0, −f_r.bias)` → `gate = 1.70 − fr_bias − 0.5·fr_sigma` (보정 없으면 `1.70`, HOLD).
분산 상향도 비관 방향만: `σ_cal = sqrt(σ_ens² + max(0, σ_resid² − mean σ_ens²))`.
모델 정체성은 `model_fingerprint`(가중치 다이제스트)로 잠그며 불일치 시 `ModelMismatchError`.
`MIN_CELL_ROWS = 12`. 실측 fold C 편향 `node_peak −0.147` / `map_cov −0.058`.

### 5.4 σ 보정 버그 2건과 수리 (2026-07-25, 재학습 불필요)

**버그 ① — 미초기화 메모리.** 챔피언 앙상블은 `promote_max_asm_bu`로 **8타깃**인데
`calibration.json`은 **7타깃**이었다 (동결-미세조정이 구 아티팩트를 그대로 복사).
`apply_calibration`이 `out = np.empty_like(...)` 후 7개만 루프 → **8번째 열이 미기록 =
힙 쓰레기가 `max_assembly_burnup`의 σ로 서빙**되었다.
**수리:** `out = total_sigma.copy()`(미적합 타깃은 원시 σ 통과) + `target_names` 인자로
**이름 기반 매핑**(부분집합·순서변경 안전). 회귀테스트 3개 추가(20회 반복 결정성, 이름 매핑,
위치 폴백).

**버그 ② — cyclen σ 866 EFPD.** `fit_calibration`이 `ensemble_stats`의 **물리 프라이어를
되더하지 않은 잔차 평균**을 절대 cyclen 정답과 비교했다. 학습된 "오차"가 프라이어 크기 전체가
되어 챔피언 isotonic이 x∈[10.9, 181.9] → **y∈[861, 983]** 로 매핑되었다 (실제 오차 3.5의 250배).
**수리:** fit 시점에 서빙과 동일하게 프라이어를 복원한 뒤 오차를 산출 → **재학습 없이 보정
재적합만으로 해결**.

**관련 결함 (2026-07-19 적대적 검토 L3-C).** pin σ isotonic이 **학습에서 마스킹된
Dataset-A 대리 잔차로 96% 적합**되었다 — 학습은 `censor_dataset_a_pin_labels=True`인데
보정은 `False` 하드코딩. A와 P는 pin/assembly 비가 1.080 vs 1.181로 **서로 다른 물리량**이다.
P 기준 적정 σ_cal 4.83 대비 서빙값 8.43 = **1.75× 과대**. 소비처(`pin_bu_limit`)가 기본

### 5.5 컨포멀 래퍼

`lpopt/model/conformal.py`가 **분포 무가정 주변 커버리지 보장**을 추가한다 (report-only, 가법적).
- 비적합도: 타깃별 `|pred − actual|`(`abs`) 또는 σ 정규화 `|pred − actual| / σ_cal`(`norm`).
  타입은 적합 시점에 **2-fold 셀 스플릿 검증**으로 타깃별 선택 (커버리지가 유효하면서 구간이
  좁은 쪽 승리).
- 분위수: 유한표본 보정 split-conformal `sorted(scores)[ceil((n+1)(1−α))−1]`, α ∈ {0.10, 0.32}.
- 셀 키: 서브 레시피와 **동일한** `(feed, e_core-bin)` 키 (파리티 정확성).
- 적합 행: 챔피언의 **정직 per-cell 홀드아웃**(정직 게이트가 채점하는 바로 그 행).
- 대상: `f_r`(0), `cbc_max`(1), `f_q`(2), `cyclen`(3), `ao_abs`(4), `max_pin_burnup`(6).
  `max_assembly_burnup` / `discharge_burnup`은 **제외**.
- 셀 폭 `0.25`(커리큘럼 밴드 1개 — `cell_calibrate`의 0.05보다 의도적으로 거침),
  `min_cell 20` 미달 시 타깃별 전역 폴백. 아티팩트 `conformal.json`, schema `split_conformal_v1`.
  **등온이 아니라 경험 분위수**다.

동기: 챔피언의 등온 σ는 주변(marginal) 적합이지 유한표본 커버리지 보장이 아니며, 정직
홀드아웃에서 z-스코어가 1에서 이탈한다 (F_q/F_r/cyclen은 under-dispersed, CBC_max·pin-BU는 over).
2026-07-25 실측: **명목 80% 분위수 구간이 실제 16~24%만 덮었다** — 불확실성 전면 붕괴.

### 6.3 셀내 ρ 0.99 목표 판정 — 라벨 잡음은 병목이 아니다

**직접 측정 (2026-07-25).** `delta_efpd`(마지막 두 사이클 cyclen 증분 실측값, Dataset A 38,851행):
중앙 0.054, **RMS 0.104 EFPD**. `tolerance_margin`(Dataset P 9,679행): 중앙 0.200, **1.0 초과 0건**.
셀내 실측 SD(cyclen 8.17 EFPD)와 비교하면 λ = σ_noise/σ_signal ≤ **0.018** → **ρ 상한 0.9998–1.0000**.

**전치쌍 직접 측정 (2026-07-25, 24쌍 발사 / 22쌍 양측 수렴 = 48 MASTER 콜).**
사분면 패턴 `p`와 그 대각 전치 `T(p)`는 **동일 물리 노심의 다른 표현**이지만 우리에게는 서로 다른
레코드다(digest·캐시키가 달라 dedup되지 않고 MASTER가 실제로 두 번 돈다). 쌍 차이는 **순수
재현성 잡음**이다.

| 라벨 | σ (무가정 = SD(d)/√2) | 전역 상한 ρ |
|---|---:|---:|
| `f_r` | 0.00595 | 0.9999 |
| `f_q` | 0.00869 | 1.0000 |
| `cbc_max` | **0.31267 ppm** | 1.0000 |
| `cyclen` | **0.08023 EFPD** | 1.0000 |
| `ao_abs` | 0.00018 | 0.9999 |
| `max_assembly_burnup` | 0.02701 | 1.0000 |
| `node_peak` (2026-07-26 맵 재파싱) | **0.005556** | 0.9997 |
| `map_cov` (동상) | **0.000507** | 1.0000 |

**★단 하나의 반전 — F_r 결정 밴드.** 경계에서 신호 SD가 붕괴하는데 잡음은 상수다:

| 밴드 | n | 신호 SD | **상한 ρ** |
|---|---:|---:|---:|
| **F_r < 1.55** | 744 | 0.00917 | **0.8387** |
| F_r < 1.60 | 1,328 | 0.02371 | 0.9699 |
| F_r < 1.65 | 4,001 | 0.03819 | 0.9881 |
| F_r 전역 | 50,786 | 0.41852 | 0.9999 |

경계에서 σ = 0.00595는 신호폭 0.00917의 **65%** — 완벽한 물리 모델도 ρ 0.84를 넘을 수 없다.
챔피언의 경계 F_r 순위스킬 ≈ −0.02는 **상당 부분 라벨 분해능 한계이지 모델 결함이 아니다.**
반대로 `map_cov`(이미 평탄한 대역) 상한 0.998 vs 실측 0.192, `node_peak` 상한 0.973 vs 0.101은
**전적으로 모델 문제**다.

**★MASTER는 비트 결정론적이다 (2026-07-26).** 48개 타깃 digest가 각각 두 개의 작업디렉터리를
남겼고(별도 `mkdtemp`, 별도 프로세스), `MAS_SUM` 바이트 비교 결과 **46/46 동일, 불일치 0**.
→ 측정된 잡음은 확률적 솔버 잡음이 아니라 **순수 표현(representational) 잡음**(슬롯 순서·메시 배정)이다.
**이것이 "같은 패턴을 k회 반복해 평균내면 σ → σ/√k" 처방을 무효화한다** — 반복은 비트 동일한
답을 준다. 평균낼 수 있는 것은 서로 다른 *표현*뿐이고 사분면 대칭군은 {p, T(p)} 2원소이므로
**k는 2에서 막히고 σ 감소는 1/√2 (−29%)에 2배 비용**이다.

**MASTER tol 강화는 실측 기각.** 허용오차 반감은 ~+1 사이클(중앙 n_cycles 9–10 → **+10~20% 계산비**)에
상한을 0.9998 → 0.9999로 움직인다 — 실제 격차(0.65–0.89 → 0.99)에 **기여 0.000**.

**0.99의 가격표** (fold C 셀내 오차 SD 축소 배수): CBC **3.7×** · AO 6.3× · cyclen 6.8× ·
F_r 7.9× · F_q 9.1× · MaxAsmBU 9.4× · **node_peak 12.4×**.

**학습곡선 — 포화하지 않으나 지수가 너무 얕다.** 셀별 로컬 전문가(PCA-120 + GBT)를
n = 25 → 2,400으로 스윕: cyclen 0.739 → **0.964**로 단조 상승(포화 없음). 그러나
λ ∝ n^(−0.206 … −0.377):

### 6.8 `F_xy` 헤드 — arm 1 → arm 3 판정 전말 (2026-08-29~30)

목적축이 바뀌면 서로게이트에 그 축의 헤드가 있어야 한다. 프록시(`F_xy ≈ a·F_r + b`)는 셀
**간** 레벨은 맞히지만 셀 **내** 기울기가 0.48로 무력하고, 개입 웨이브가 나중에 밝힌 대로
Gd·격자 무브에서는 전달계수 자체가 다르다(→ [03](03_search_policy_autoeng.md)). 그래서 세
arm이 돌았고, **두 번 떨어지고 세 번째에 통과**했다.

1. **잔차 헤드가 사실상 학습되지 않았다.** `HEAD − prior(예측 F_r)`의 sd가 0.0259 = 라벨

3. **`calibration.json`에 `f_xy` 곡선이 없었다**(모듈 상수 7열만 순회) → G4는 **구조적으로
   도달 불가**했다.

**그리고 근본 문제 하나가 남아 있었다** — MAE 분해가 그것을 보여준다:

MAE 0.1086 → **0.0669**, ρ̄ 0.768 → **0.785**, bias −0.0889 → **−0.0008**이었다.

## 8. 수용 기준 (acceptance bar)

> **사용자 확정 (2026-07-30).** 모델의 최종 목표는 **노드 출력이 평탄하고 특정 주기길이 +
> design constraints를 만족하는 노심을 예측하고, 그 장전모형을 실제 MASTER로 돌렸을 때
> 예측과 거의 일치하는 것**이다.

**최적 후보에서의 예측−MASTER 허용치:**

| 축 | 허용치 | 현 상태 (참고) |
|---|---|---|
| `cyclen` | **≤ 1 EFPD** | 전역 MAE 2.87 EFPD (s1f, 고정면) / 전이쌍 잡음 하한 0.080 EFPD |
| `CBC_max` | **≤ 1 ppm** | 전역 MAE 23.4 ppm / 전이쌍 잡음 하한 0.31 ppm |
| `F_q`, `map_cov`, `node_peak` | 수십 pcm 수준 (**~0.001 오더**) | node_peak MAE 0.101, map_cov MAE 0.0217 / 잡음 하한 0.00556, 0.000507 |
| `AO` | 아직 중요하지 않음 | 전 코퍼스 \|AO\| < 0.30 (§4.5) |

**왜 이것이 합격선인가.** 전역 MAE(3.99 EFPD / 28 ppm @2026-07-30)가 아니라
**캠페인이 실제 제안하는 최적 후보에서의 일치**가 기준이다. 허용치는 전이쌍으로 실측한
잡음 하한(cyclen 0.080 EFPD, CBC 0.31 ppm) **위**에 있으므로 물리적으로 도달 가능하다.

**적용 방법.** 모든 `flat_power` / `user_criteria` 캠페인의 웨이브 parity와 debug-panel
허용치를 이 값으로 판정하고, 검증된 최적 후보의 |예측 − 실측|를 **1차 KPI**로 보고한다.
사례 (2026-07-21 스팟체크): 셀 (5.5 w/o, feed 109, 목표 625 EFPD)에서 best |Δcyclen| = **1.35 EFPD**.
(같은 점검에서 feed 117은 물리 한계 — 자연 주기길이 666 EFPD — 로 목표 밖이었고,
이것이 `user_criteria` 모드에 **feed 자유도**가 필수임을 실증했다.)

**AB2 사전등록이 기록한 격차 (2026-07-30):** CBC |오차| 중앙 15.7 ppm vs 목표 ≤1 ppm = **16×**,
node_peak 0.021 vs ~1e-3 = **20×**. 이 두 숫자가 남은 작업의 크기를 정직하게 말해 준다.

**`min_fxy` r1이 실제 최적점에서 잰 값 (2026-08-30, 95행 캠페인 · 우승 코어 `bf3a70b2`).**
수용 기준은 "**최적 후보에서**"의 일치이므로, 이 캠페인이 처음으로 그 기준을 새 목적축에서
직접 채점했다.

| 축 | 허용치 | 우승 코어에서 \|예측 − 실측\| | 판정 | 캠페인 전체(95행) MAE |
|---|---|---:|---|---:|
| `cyclen` | ≤ 1 EFPD | **0.349** | **PASS** | 0.905 EFPD |
| `CBC_max` | ≤ 1 ppm | **3.572** | **FAIL** (3.6×) | 7.646 ppm |
| `f_xy` (헤드) | ≤ 0.01 (등록) | **0.0543** | **FAIL** (5.4×) | 0.0514 |
| `F_r` | 보고만 | 0.0034 | — | 0.0453 |

`cyclen`은 통과했고 CBC는 **16× → 3.6×**로 좁혀졌다(보정 재적합의 효과). 새로 생긴 격차는
`f_xy` 헤드의 **5.4×**이며, 이것이 r2의 게이팅 항목으로 등록됐다. 3종 라운드 2에서는 같은
기준이 모집단 수준에서 어떻게 보이는지도 측정됐다 — `cyclen ≤ 1` **29/58**,
`CBC ≤ 1 ppm` **6/58 (10.3%)**, 둘 다 **3/58**. **수용 기준은 최적점에서만 만족되고
모집단에서는 아직 아니다** — 이것이 기준의 원래 문장 그대로다.

**챔피언 로딩:**
```python
from lpopt.model.model_api import PosValCnnBackend
```

백엔드는 **체크포인트 자신의 `meta.json`에서 인코더를 재구성**하고, 스키마가 불일치하는

(현 시점 알려진 불일치: `lpopt.inp`의 `cond_schema = "v7"`이 `s1i`의 실제 `v8`과 어긋나 있다 —
`gate-promote`가 `model_dir`만 다시 쓰고 이 키는 수동 갱신 대상이기 때문. 서빙 영향은 없으나
덱이 자기 챔피언을 잘못 기술하고 있다.)

**반드시 serve 경로를 쓸 것:** `predict()` / `predict_map_flatness()`.
cyclen 물리 프라이어 되더하기가 이 경로 **안에만** 있다 (§3.4).

**추론 백엔드 (덱 `[model] inference`):**

| N | 로컬 CPU | 원격 GPU (e2e) | 원격 GPU (steady) | 속도비 (e2e) |
|---:|---:|---:|---:|---:|
| 2,000 | 13.45 s (148.7 pred/s) | 9.43 s (212.1) | 5.69 s (351.6) | 1.43× |
| 20,000 | 193.22 s (103.5 pred/s) | 55.22 s (362.2) | 47.30 s (422.9) | **3.50×** |

원격 경로는 압축 패턴(`Pattern.canonical()`, ~0.6 KB)과 `CaseKey`를 보내고 **원시 앙상블 배열**을
그대로 돌려받으므로 denorm + 보정 스택이 로컬과 동일하게 재사용된다 (결과 일치 |Δf_r| ≤ 1.4e-3).
서버 도달 불가 또는 배치 전송 오류 시 **큰 소리로 로그를 남기고 로컬 CPU로 폴백**한다 (부분 점수 없음).
